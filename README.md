# Attendance-Tracker-for-Participants  
# 🚀 GFG Event Attendance & Analytics Suite

An interactive web dashboard built for campus event organizers to manage participant registration, track real-time attendance, generate QR check-in passes, and export attendance logs.

---

## ✨ Features

- **Live Analytics:** Dynamic visual attendance tracking powered by Chart.js.
- **Digital QR Passes:** Automatic client-side QR pass generation for registered participants.
- **Data Persistence:** Browser `LocalStorage` support preserves records across sessions.
- **Quick Controls:** Instant multi-parameter search, tab filters, and bulk status updates.
- **Export Capabilities:** One-click `.CSV` report downloads.
- **Modern UI:** Responsive layout with dark and light theme toggles.

---

## 🛠️ Built With

- **Core:** HTML5, CSS3, JavaScript (ES6+)
- **Libraries:** Chart.js, QRCode.js, FontAwesome Icons
